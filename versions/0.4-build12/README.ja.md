# Orchard 🍎 0.4 — build12

ZIPを1回展開し、`Orchard` の **Orchard.app** を開きます。説明書は **はじめに・説明書** にあります。
[画像付き初回導入](INSTALL.ja.md) / [更新と登録引き継ぎ](UPDATE.ja.md) / [操作ガイド](GUIDE.ja.md) / [検証状況・変更点](RELEASE_NOTES.md)。

ZIPの静的な疑わしい指示検査とSHA-256照合は別機能です。実300,000 unique件は旧100,000件すべてと実追加200,000件です。最新30万件・全期間収録ではありません。一致も未一致も調査の先行手掛かりで、安全・危険の確定や実行許可ではありません。[出典と収録範囲](DATA_SOURCES.md)。

経過時間だけで照合を止めず、取得日時・収録範囲を表示します。DB異常、検査不能、許諾撤回などの保留は維持します。自動更新はOFFです。

GitHubを使わないMac内の開発フォルダも登録できます。対応MDがなくても登録でき、監視中の新規作成を検知します。登録は1フォルダ、監視は手動開始です。常時監視やすべてのAI書込みの阻止は保証しません。更新時は旧登録・未確認変更を検証し、互換性がある保存先を参照します。旧版が監視中・登録破損などの場合は、未登録へ初期化せず理由を表示します。

Apple Silicon・macOS26以降。Python/SQLite同梱、ad-hoc署名・Apple公証なし。個別承認は安全保証ではありません。
