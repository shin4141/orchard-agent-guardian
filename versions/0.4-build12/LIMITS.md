# Limits / 限界 — build12

- Stored SHA-256: 300,000 unique, a limited subset, neither newest nor complete. No broad malware-detection guarantee. Internal lookup agreement is not a malicious-ZIP detection rate.
- SHA matching and static instruction rules are separate investigative leads, not safety/danger verdicts or permission to execute.
- One local-folder registration; manual monitoring. No continuous-monitoring, writer-attribution or all-AI-write prevention guarantee.
- Apple Silicon/macOS26+, ad-hoc signed, not notarized. App-specific approval does not guarantee safety.
- Automatic updates and login registration OFF. Age alone does not stop stored-snapshot lookup. Integrity, inspection, clock, update-failure and withdrawal checks remain.
- Build12's three disposable-state native cases passed: pending-zero/one adoption, subsequent manual monitoring/review/stop, and invalid-registration refusal. Earlier trial artifacts timed out for an unconfirmed reason; that was not reproduced in these fixed-artifact cases. No universal update-success guarantee, Internet installation, another-Mac operation, runtime Sandbox enforcement or OS menu-bar image pass is claimed. See [acceptance status](RELEASE_NOTES.md).
- Build12 first-use GUI paths remain untested: the initial unregistered display, and registering/saving a new project. The three existing-registration GUI cases do not validate these paths. build12の初回利用時の未登録表示、新規プロジェクト登録・保存の実GUI試験は未実施です。既存登録の引き継ぎ等3ケースのPASSとは区別します。
