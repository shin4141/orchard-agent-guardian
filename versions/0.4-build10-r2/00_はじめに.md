# はじめに — Orchard 🍎

アプリを使う：この説明書フォルダの **1つ上** に戻り、**Orchard.app** をダブルクリックします。説明を読む：このフォルダ内の [README.ja.md](README.ja.md) と [操作ガイド](GUIDE.ja.md) を開きます。

## 初回起動でmacOSに止められたら

Orchardはad-hoc署名・Apple公証なしです。配布元とchecksumを確認した上で、システム設定 → プライバシーとセキュリティのOrchard欄から **このまま開く** を選びます。続く確認も含め、[画像付き手順](INSTALL.ja.md#orchardを開く)を先に読んでください。

![macOSのOrchardブロック表示と、このまま開く](images/first-launch-blocked.ja.png)

個別承認は安全保証ではありません。Gatekeeper全体の無効化やquarantine削除は不要です。破損・既知の危険・管理ポリシー等の別警告では停止してください。OSが本人認証を求めた場合はOS画面で本人が対応します。パスワードを問い合わせへ送りません。

## 最初の無害な操作例

アプリの「ZIPを選んで照合」で、この説明書フォルダ内の [examples/benign-notes.zip](examples/benign-notes.zip) を選びます。見守りの練習には `examples/sentinel-project` の使い捨て例を使い、[操作ガイド](GUIDE.ja.md)の順に進めます。

これは配布の並べ方だけを変えたr2で、アプリはOrchard 0.4 build10のままです。実SHA100,000件は固定の限定subset、照合結果は安全保証ではなく、自動更新はOFFです。別Macでの初回利用は未確認です。ライセンス資料をアプリと一緒に保持してください。[English installation](INSTALL.md) / [ライセンス](THIRD_PARTY_NOTICES.md)。
